# Funniest Time Machine Warning Label — Entry v2

This repository is an entry for the Funniest Time Machine Warning Label bounty on make.fun. The program in `main.py` writes a single deadpan warning label about the duplicate-self hazard of time travel to `/output/entry.txt`.

## About this entry

The label treats the duplicate-self hazard as an occupancy problem: the machine seats one, so meeting yourself leaves one of you officially uncovered. It keeps a completely straight face — pure safety-manual phrasing — and withholds the entire joke for the final three words, when the uncovered duplicate is told, in effect, to walk home. The hazard is never named as a "paradox"; the petty bureaucratic consequence is the punchline.
